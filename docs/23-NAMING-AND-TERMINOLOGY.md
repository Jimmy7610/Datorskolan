# Namn och terminologi

## Arbetsnamn

Projektets arbetsnamn är `Datorskolan`.

Namnet kan ändras senare.

## Termer

Använd helst:

- muspekare
- vänsterklick
- högerklick
- dubbelklick
- scrolla/rulla
- dra och släpp
- skrivbord
- Start-menyn
- aktivitetsfält
- program
- fil
- mapp
- webbläsare
- adressfält
- flik

## Termintroduktion

Visa alltid först vad något är innan ordet förväntas vara känt.

## Kodnamn

Kod använder engelska id:n:

- `mouse.move`
- `mouse.leftClick`
- `mouse.doubleClick`
- `windows.startMenu`
- `files.createFolder`

Användargränssnittet kan vara svenskt.
