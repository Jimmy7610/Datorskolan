# Landing page / Product shell – Acceptance

Landningssidan är godkänd först när följande fungerar i publicerad GitHub Pages-version.

## Första intryck

- [ ] Startsidan visas istället för simulatorn vid första laddning.
- [ ] Datorskolans namn och produktlöfte är tydliga direkt.
- [ ] Hero-sektionen känns som en riktig produktstartsida.
- [ ] Simulator-previewn visas korrekt.
- [ ] Sidan har inga trasiga eller överlappande element på vanlig desktop.

## Navigation

- [ ] Så fungerar det scrollar till rätt sektion.
- [ ] Innehåll scrollar till kursöversikten.
- [ ] Tryggt att öva scrollar till säkerhetssektionen.
- [ ] Headern förblir tydlig när sidan scrollas.

## Start / Fortsätt

- [ ] Starta Datorskolan öppnar simulatorn.
- [ ] 🎓-panelen öppnas automatiskt efter start.
- [ ] Startsida-knappen visas i simulatorn.
- [ ] Startsida-knappen tar användaren tillbaka till landningssidan.
- [ ] Om progress finns visas Fortsätt Datorskolan istället för Starta Datorskolan.
- [ ] Sparad progress påverkas inte av att växla mellan landing page och simulator.

## Innehåll

- [ ] Så fungerar det visar fyra pedagogiska steg.
- [ ] Kursöversikten visar Mus, Tangentbord, Windows, Filer & mappar, Internet, E-post, Säkerhet och Självständighet.
- [ ] Trygghetssektionen förklarar att simulatorn inte påverkar riktiga filer.
- [ ] Slutlig CTA finns längst ner.

## Responsivitet

- [ ] Desktop-layout fungerar vid normal Windows-upplösning.
- [ ] Layouten fungerar på mindre laptopfönster.
- [ ] Mobil layout staplar innehållet utan horisontell landningsside-scroll.
- [ ] CTA-knappar är fortfarande läsbara och klickbara.

## Tillgänglighet

- [ ] Huvudnavigation har tydlig aria-label.
- [ ] Startknappar har tydlig aria-label.
- [ ] Fokusmarkering syns vid tangentbordsnavigation.
- [ ] Reducerad animation respekteras.
- [ ] Textkontrast är läsbar.
- [ ] Dekorativa simulator-element stör inte skärmläsare.

## Regression

- [ ] Fake Windows startar fortfarande korrekt.
- [ ] Lesson Engine fungerar fortfarande.
- [ ] Progress finns kvar efter omladdning.
- [ ] Scenario Engine fungerar fortfarande.
- [ ] Inga console errors under normal användning.
- [ ] GitHub Actions är grön.
