# Progression och adaptivitet

## Startdiagnos

Användaren ska kunna börja med en kort praktisk diagnos.

Diagnosen frågar inte: "Hur bra är du på datorer?" Den låter användaren göra saker.

Exempel:
- flytta musen,
- klicka,
- dubbelklicka,
- skriva sitt namn,
- öppna Start,
- öppna en mapp.

## Anpassning

Om användaren klarar en färdighet säkert:
- hoppa över grundintroduktion,
- ge kortare övning,
- gå vidare.

Om användaren misslyckas:
- sänk svårighet,
- ge hjälp,
- repetera.

## Spaced repetition

Viktiga färdigheter ska återkomma senare. Exempel: dubbelklick tränas i modul 1, men testas igen i modul 4.

## Dashboard

Visa hellre färdighetsområden än betyg.

```text
Mus            85%
Tangentbord    60%
Windows        25%
Filer          10%
Internet       0%
```

## Barnläge

Kan visa stjärnor, nivåer eller karta.

## Vuxenläge

Kan visa checklistor och tydlig progression.
