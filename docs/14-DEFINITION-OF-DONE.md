# Definition of Done

En feature är inte klar bara för att den "fungerar".

## Kod

- implementation klar,
- inga console errors,
- begriplig struktur,
- inga onödiga beroenden,
- relevanta tester finns.

## UX

- uppgiften går att förstå,
- fel ger begriplig feedback,
- hjälp fungerar,
- användaren kan komma vidare.

## Pedagogik

- färdigheten är tydligt definierad,
- success kan mätas,
- övningen motsvarar färdigheten,
- nivån passar målgruppen.

## Tillgänglighet

- fokus syns,
- text är läsbar,
- kontrast är acceptabel,
- reducerad animation respekteras där relevant.

## Dokumentation

- berörd dokumentation uppdaterad,
- nya lesson types dokumenterade,
- nya events dokumenterade,
- nya settings dokumenterade.

## Publicering

- GitHub Pages bygger,
- startsidan fungerar,
- ingen trasig asset-path,
- localStorage-version hanteras.
