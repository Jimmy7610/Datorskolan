# UX/UI-specifikation

## Huvudprinciper

- mycket stora klickytor,
- hög kontrast,
- tydlig typografi,
- en primär uppgift per vy,
- få visuella distraktioner,
- alltid tydlig "fortsätt"-logik,
- hjälp ska finnas men inte dominera.

## Grundlayout

### Övre område
- modulnamn,
- kort framstegsindikator,
- eventuell hemknapp.

### Huvudyta
- instruktion,
- interaktiv övning.

### Nedre område
- Hjälp
- Förklara igen
- Paus
- Fortsätt när relevant

## Undvik

- små länkar,
- dropdowns utan förklaring i tidiga nivåer,
- mycket text,
- animationer utan funktion,
- straffande felmeddelanden,
- teknisk jargon.

## Feedback

Bra:
- "Du hittade rätt."
- "Försök igen."
- "Nästan. Klicka en gång, inte två."
- "Vill du ha en ledtråd?"

Undvik:
- "Fel!"
- "Misslyckades!"
- "Du gjorde fel."

## Responsivitet

Projektets primära mål är Windows-dator med mus och tangentbord.

Sidan får fungera på mobil, men utbildningsmoment för mus och Windows behöver inte vara fullvärdiga på touchskärm.
