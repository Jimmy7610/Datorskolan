# Fas 3 – Mus Acceptance

Fas 3 är godkänd först när följande fungerar i publicerad GitHub Pages-version.

## Modulöversikt

- [ ] Mus visas som modul i Datorskolan.
- [ ] Nio muslektioner finns.
- [ ] Varje lektion öppnar Mouse Lab automatiskt.
- [ ] Lesson Engine-panelen ligger kvar under övningen.
- [ ] Framsteg sparas mellan omladdningar.

## Lektion 1 – Muspekaren

- [ ] Träningsytan reagerar på pointer movement.
- [ ] Progressmätaren ökar med faktisk rörelsesträcka.
- [ ] Lektionen blir klar först efter definierad rörelsesträcka.
- [ ] Skill `mouse.move` registreras.

## Lektion 2 – Träffa ett mål

- [ ] Mål 1, 2 och 3 visas.
- [ ] Målen måste träffas i rätt ordning.
- [ ] Ingen klickning krävs.
- [ ] Skill `mouse.precision` registreras.

## Lektion 3 – Vänsterklick

- [ ] Ett enkelklick godkänns.
- [ ] Dubbelklick ger neutral korrigerande feedback.
- [ ] Skill `mouse.left-click` registreras.

## Lektion 4 – Dubbelklick

- [ ] Två snabba klick på samma mål godkänns.
- [ ] Ett vanligt enkelklick avslutar inte övningen.
- [ ] Skill `mouse.double-click` registreras.

## Lektion 5 – Högerklick

- [ ] Vänsterklick ger neutral korrigerande feedback.
- [ ] Högerklick godkänns.
- [ ] Browserns vanliga context menu visas inte inne i målet.
- [ ] Skill `mouse.right-click` registreras.

## Lektion 6 – Scroll

- [ ] Träningsrutan kan scrollas.
- [ ] Scroll nedåt registreras.
- [ ] Scroll uppåt efteråt registreras.
- [ ] Båda riktningar krävs för success.
- [ ] Skill `mouse.scroll` registreras.

## Lektion 7 – Klicka och håll

- [ ] Vänster musknapp måste hållas nere ungefär en sekund.
- [ ] För tidigt släpp ger neutral hjälp.
- [ ] Mätaren visar hållmomentet.
- [ ] Skill `mouse.hold` registreras.

## Lektion 8 – Dra och släpp

- [ ] Objektet kan dras.
- [ ] Drop-zonen reagerar när objektet förs över den.
- [ ] Släpp i rätt område godkänns.
- [ ] Skill `mouse.drag-drop` registreras.

## Lektion 9 – Slutuppdrag

- [ ] Sex moment visas samtidigt.
- [ ] Flytta registreras.
- [ ] Vänsterklick registreras.
- [ ] Dubbelklick registreras.
- [ ] Högerklick registreras.
- [ ] Scroll ned/upp registreras.
- [ ] Dra/släpp registreras.
- [ ] Varje färdigt moment får tydlig bock.
- [ ] Uppdraget blir klart först när alla sex är genomförda.
- [ ] Slutuppdraget använder flera tidigare skills.

## Hjälptrappa och mastery

- [ ] Hjälp 1–5 fungerar i alla kärnövningar.
- [ ] Nivå 4 markerar relevant träningsområde.
- [ ] Hintnivå registreras i progress.
- [ ] Självständiga successer registreras när ingen hjälp används.
- [ ] Mus-skills kan utvecklas mot independent/mastered.

## Regression

- [ ] Landing page fungerar.
- [ ] Fake Windows fungerar.
- [ ] Lesson Engine fungerar.
- [ ] Scenario Engine fungerar.
- [ ] Filer/Notepad/Photos/Calculator fungerar.
- [ ] Inga console errors under normal användning.
- [ ] GitHub Actions är grön.
- [ ] Mouse module smoke test är grön.
