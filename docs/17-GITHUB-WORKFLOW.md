# GitHub-workflow

## Brancher

- `main` = stabil
- feature branches för större arbete

Exempel:
- `feature/mouse-module`
- `feature/window-manager`
- `fix/drag-drop-target`

## Commit-format

Exempel:
- `feat: add pointer movement exercise`
- `fix: prevent double-click false positive`
- `docs: define mouse mastery rules`
- `test: add lesson validator coverage`

## Pull requests

PR ska beskriva:
- vad som ändrats,
- varför,
- hur det testats,
- eventuella dokumentationsändringar.

## GitHub Pages

Publicera från `main` eller GitHub Actions enligt valt upplägg.

## Issues

Använd labels:
- feature
- bug
- lesson
- simulator
- ux
- accessibility
- documentation
- testing
- security
