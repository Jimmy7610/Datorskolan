# Fas 12 – Vardagsdatorn och djupare förståelse – Acceptance

Fas 12 är implementerad men markeras inte som slutligt godkänd förrän den publicerade GitHub Pages-versionen är manuellt verifierad.

## Kursomfattning

- [ ] Kursen visar minst 120 lektioner.
- [ ] Vardagsdatorn visas som egen modul.
- [ ] Enheter & anslutningar visas som egen modul.
- [ ] När något krånglar visas som egen modul.
- [ ] Självständighetsprovet ligger sist i modulordningen.
- [ ] Befintlig progress från de första 81 lektionerna finns kvar efter uppdateringen.

## Förstå först

Varje lektion ska innehålla:

- [ ] Vad är det?
- [ ] Hur känner jag igen det?
- [ ] Vad används det till?
- [ ] Exempel.
- [ ] Vanligt i vardagen med minst två exempel.
- [ ] Vanliga misstag med minst två exempel.
