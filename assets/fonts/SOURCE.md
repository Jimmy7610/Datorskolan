# Cooper Hewitt font source

Datorskolan uses **Cooper Hewitt**, created by Chester Jenkins for Cooper Hewitt, Smithsonian Design Museum.

Official information:
- https://www.cooperhewitt.org/open-source-at-cooper-hewitt/cooper-hewitt-the-typeface-by-chester-jenkins/
- https://github.com/cooperhewitt/cooperhewitt-typeface

License: **SIL Open Font License 1.1**. See `CooperHewitt-OFL.txt`.

For browser delivery, Datorskolan references the Windows-compatible Cooper Hewitt files from the repository linked by Cooper Hewitt's official download page, pinned to commit:

`24437eb6fc8bbf1fe8c518eeeaabd3012dffed4c`

Weights used:
- Book 400
- Medium 500
- Semibold 600
- Bold 700
